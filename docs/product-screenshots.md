# Main Ments product screenshots

Captured from the live web app on 2026-09-23 at a 1440 × 1000 desktop viewport.

- `public/product/ments-startups.png`: `https://www.ments.app/startup`, shown in the homepage hero.
- `public/product/ments-events.png`: `https://www.ments.app/events`, shown in the first product-preview tab.

These are actual rendered app screens using the existing founder test account.
Only the test account button was hidden in the browser before capture; the
product interface and listed content were not replaced or fabricated. No
messages, account settings, or private profile screens were captured.

Next.js static imports and its image optimizer provide responsive delivery.
The existing startup and partner dashboard previews remain separate tabs.
Full-size preview links open the original image in a new tab.

To refresh, capture the same routes and viewport, wait for the visible content
and images to load, hide the test account button, and replace the two PNGs.
